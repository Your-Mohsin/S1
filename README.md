# house-price-prediction

An app that will predict the price of a house based on its property details.

You can run the app here-

https://4xhajw8oyewgen2rwbyzub.streamlit.app/

The application will take the input data from the user
(area, number of bedrooms, city, location, car parking,
swimming pool, 24X7 security, lift availability, club house, etc.)
and use the trained machine learning model to predict the
estimated price of the house.

The project contains the following files:

• app.py – the script of the web application

• city_encoder.joblib – encoder for the city variable

• data.csv – the dataset used for training and analysis

• final_data.csv – the cleaned/processed data used for training

• index.ipynb – a Jupyter Notebook containing the code used
for data analysis, preprocessing and training the machine
learning model

• index.txt – notes containing dataset analysis and key statistics

• location_encoder.joblib – encoder for the location variable

• model.joblib – the trained machine learning model
